# Домашнее задание: Крестики-нолики (кооперативное сетевое приложение)

## Цель:

Реализовать консольную игру крестики-нолики со взаимодействием по TCP между двумя игроками. Один из игроков запускает сервер, второй клиент.

---

## Требования:

### 1. Сетевое взаимодействие

- Используйте TCP для связи между клиентом и сервером.
- Сервер ожидает подключения клиента и после этого запускает игру.
- Только один игрок может ходить за раз, после хода информация отправляется партнеру.

### 2. Управление:

- Перемещение курсора по полю: стрелки на клавиатуре
- Выбор знака: `1` - Крестик, `2` - Нолик
- `Enter` — подтверждение хода
- Ввод должен обрабатываться в режиме реального времени (без ожидания Enter после каждой клавиши).

### 3. Оформление:

- Сделайте эстетичную консольную отрисовку поля (3x3)
- Отображайте текущий ход, ходы игроков, победу/ничью.

### 4. Дополнительно:

- Добавьте полностью обработку исключений: отключение сети, неверный ход, ошибки подключения.

---

## Сдача задания:

- Приложите свой .sln и .cs-файлы в репозиторий GitHub
- В README.md коротко опишите, как запустить сервер и клиента.
