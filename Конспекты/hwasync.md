# 🏠 Домашнее задание: Асинхронное программирование в C#

## 📌 Цель:

Научиться использовать ключевые конструкции `async` / `await` в C# и реализовать асинхронную обработку данных в консольном приложении.

---

## 📋 Задание:

Создайте консольное приложение, которое имитирует выполнение нескольких асинхронных задач, таких как обработка чисел, сортировка или фильтрация данных.

---

## 🎯 Требования к приложению:

1. **Список чисел**

   - Инициализируйте список из 20 случайных целых чисел от 1 до 100.
   - Отобразите их в консоли.

2. **Асинхронная фильтрация чётных чисел**

   - Метод: `Task<List<int>> FilterEvenAsync(List<int> numbers)`
   - Имитация загрузки: `await Task.Delay(1500)`
   - Верните все чётные числа из списка

3. **Асинхронная фильтрация нечётных чисел**

   - Метод: `Task<List<int>> FilterOddAsync(List<int> numbers)`
   - Имитация загрузки: `await Task.Delay(1500)`
   - Верните все нечётные числа из списка

4. **Асинхронное вычисление суммы**

   - Метод: `Task<int> CalculateSumAsync(List<int> numbers)`
   - Имитация загрузки: `await Task.Delay(1000)`
   - Верните сумму чисел

5. **Main должен:**
   - Вызвать все вышеуказанные методы
   - Использовать `await` или `Task.WhenAll`, где это возможно
   - Отобразить результаты в консоли
