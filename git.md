# Введение в git 

`Git` - это система контроля версий, которая нужна для того чтобы отслеживать изменения в файлах и папках.

### Глоссарий 
`Репозиторий` - это папка, которая остлеживается гитом
`Ветка` - это направление в вашем репозитории, которая может изменяться. В зависимости от текущей ветки показываются разные файлы
`Коммит` - это сохранение изменений в репозитории
`Пулл` - это скачивание изменений с удаленного репозитория
`Пуш` - это отправка изменений на удаленный репозиторий
`Форк` - это копирование репозитория на ваш аккаунт
`Клонирование` - это скачивание репозитория на ваш компьютер

### Настройка

Чтобы сделать обычную папку репоизиторием нужно зайти в него через консоль и сделать 
```bash
git init
```

Затем нужно настроить имя и почту, чтобы ваши коммиты были подписаны

```bash 

git config --global user.name "John Doe"
git config --global user.email "aloha@gmail.com" 

```

эта информация нужна для того чтобы другие люди могли понять кто именно сделал изменения 

### Коммиты 

После того, как вы совершили какие-то изменения в файлах, нужно сделать коммит. Для этого нужно сделать следующее:

```bash
git add .
``` 

Данная команда значит что вы добавляете изменения на очерель для подтверждения. Точка значит что надо добавить все файлы, вместо точки можно добавить название файла

После данной команды надо сделать сам коммит, в котором мы подтверждаем изменения

```bash

git commit -m "Сообщение коммита"

```

`-m` - это флаг, который значит что после него идет сообщение коммита

Затем надо добавить все в удаленный репозиторий. Давайте уйдем в начало настройки. для того чтобы в будущем вам не приходилось вводить ссылку на ваш гитхаб аккаунт, можно сделать так:

```bash 

git remote add origin <ссылка на репощиторий с гитхаба>

``` 

`origin` - это переменная, которая хранит ссылку на ваш удаленный репозиторий.

После этого надо создать новую ветку 

```bash

git checkout -b <название ветки>

```

`-b` - это флаг, который значит что надо создать новую ветку

После этого надо отправить изменения на удаленный репозиторий

```bash

git push origin <название ветки>

```
