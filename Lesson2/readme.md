# Сокеты

Сокет - это конечная точка двунаправленного канала связи между двумя программами, работающими в сети. Сокеты обеспечивают механизм для обмена данными между процессами, которые могут находиться на одной машине или на разных машинах в сети.

По факту сокет - это IP адрес и номер порта, которые вместе образуют уникальную точку доступа для передачи данных. Сокеты могут использоваться для различных протоколов, таких как TCP/IP, UDP и других.
