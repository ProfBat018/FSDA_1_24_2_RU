# Тема урока: Unicast, Multicast, Broadcast

## Unicast

Есть несколько способов отправить сообщение от одного хоста к другому.
Сегодня мы будем рассматривать все из них, но начнем с самого простого - `Unicast`

`Unicast` - это способ передачи данных от одного узла к другому.
То есть по факту вы не делаете ничего сверхестесственного, просто отправляете сообщение от одного узла к другому.
Для этого вы можете выбрать абслютно любой протокол, который вам нужен. Конкретной привязки к какому-то протоколу нет.

Все как мы делали на прошлых уроках.

## Multicast

`Multicast` - это способ передачи данных от одного узла к группе узлов. Например, вы являетесь сервером и отправляете сообщениие конкретным клиентам. Предположим такую ситуацию, что администратору нужно выключить удаленно все компьютеры в кабинете 1A. Предаврительно ему нужно оповестить всех пользователей, что через 5 минут произойдет отключение. Для этого он может использовать `Multicast` и отправить сообщение всем пользователям в кабинете 1A.

Для использования `Multicast` мы сможем использовать только `UDP` и только определнный диапазон портов. Для дальнейшего изучения давайте рассмотрим как работает `UDP`.

#### UDP

`UDP`(User Datagram Protocol) - это протокол передачи данных, который не требует установки соединения в формате потока как `TCP`. Он работает по принципу "отправил и забыл". Это значит что он не гарантирует доставку пакетов, их порядок или целостность. Для передачи он использует датаграммы, которые весят 64kb. Это значит что вы можете отправить 64kb данных + 8 byte заголовок.

Для работы с ним в C# мы также можем использовать низкоуровневые сокеты и класс `UdpClient`.
В отличие от `TCP` в `UDP` не будет класса `UdpListener`, так как он не требует установки соединения. Тут всем занимается класс `UdpClient`.

Вернемся к `Multicast`. Для работы с ним мы можем использовать `UDP` и класс `UdpClient` и range 
ip адресов от `224.0.0.0` до `239.255.255.255`. 

Это значит что вы можете использовать любой ip адрес из этого диапазона.
