# LINQ методы для EF Core

## Основные методы выборки
- **ToList** - Выполняет запрос и загружает результаты в список.
- **ToArray** - Выполняет запрос и загружает результаты в массив.
- **First** - Возвращает первый элемент последовательности, выбрасывает исключение, если элементов нет.
- **FirstOrDefault** - Возвращает первый элемент последовательности или значение по умолчанию, если элементов нет.
- **Single** - Возвращает единственный элемент последовательности, выбрасывает исключение, если элементов больше одного или нет.
- **SingleOrDefault** - Возвращает единственный элемент последовательности или значение по умолчанию, если последовательность пустая.
- **Find** - Ищет сущность по первичному ключу (работает только с DbSet).
- [**Include** - Загружает связанные данные (жадная загрузка).](https://github.com/ProfBat018/FSDE_1_24_3_RU/blob/EF/LibProj/LibProj/Program.cs)
- **ThenInclude** - Используется после Include для загрузки вложенных данных.

## Фильтрация
- **Where** - Фильтрует последовательность по заданному условию.
- **Any** - Проверяет, содержит ли последовательность хотя бы один элемент, удовлетворяющий условию.
- **All** - Проверяет, удовлетворяют ли все элементы последовательности заданному условию.
- **Contains** - Проверяет, содержит ли последовательность указанный элемент.
- **Distinct** - Убирает дублирующиеся элементы из последовательности.
- **Skip** - Пропускает указанное количество элементов в последовательности.
- **Take** - Берет указанное количество элементов из последовательности.

## Сортировка
- **OrderBy** - Сортирует последовательность по возрастанию.
- **OrderByDescending** - Сортирует последовательность по убыванию.
- **ThenBy** - Добавляет дополнительный уровень сортировки по возрастанию.
- **ThenByDescending** - Добавляет дополнительный уровень сортировки по убыванию.
- **Reverse** - Переворачивает порядок элементов в последовательности.

## Группировка и агрегирование
- **GroupBy** - Группирует элементы по заданному критерию.
- **Sum** - Вычисляет сумму значений в последовательности.
- **Average** - Вычисляет среднее значение в последовательности.
- **Min** - Определяет минимальное значение в последовательности.
- **Max** - Определяет максимальное значение в последовательности.
- **Count** - Подсчитывает количество элементов в последовательности.

## Проецирование
- **Select** - Преобразует элементы последовательности в новый формат.
- **SelectMany** - Преобразует и объединяет вложенные коллекции в одну последовательность.

## Объединение
- **Join** - Выполняет внутреннее соединение двух последовательностей по ключу.
- **GroupJoin** - Выполняет группирующее соединение двух последовательностей.
- **Concat** - Объединяет две последовательности в одну.
- **Union** - Объединяет две последовательности и удаляет дублирующиеся элементы.
- **Intersect** - Возвращает общие элементы двух последовательностей.
- **Except** - Возвращает разницу между двумя последовательностями.

## Прочие методы
- **AsNoTracking** - Отключает отслеживание изменений для загружаемых сущностей.
- **AsQueryable** - Преобразует коллекцию в IQueryable.
- **AsEnumerable** - Преобразует IQueryable в IEnumerable.
- **DefaultIfEmpty** - Возвращает последовательность из одного элемента по умолчанию, если исходная последовательность пуста.
- **SelectExpression** - Позволяет явно указать SQL-выражение для выборки данных.
