# Что такое Fluent API ? 

`Fluent API` - это определение поведения ваших сущностей в 
базе данных с помощью инструкций в C#, путем переопределения базового 
метода `OnModelCreating` в классе наследующем `DbContext`.

Таким образом мы можем задать что является `primary key`, `foreign key`,
задать обязательные колонки, длину строк и многое другое. По идее этот подход
полностью заменяет нам `Data Annotations` и делает наш код более читаемым и
понятным.

# Зачем Data Annotations - это не лучшая практика ?

Еще с C# мы пытались разделять бизнес модель от бизнес логики. 
В модели, где мы описываем наши сущности, мы не должны прописывать какую-либо
логику. Считайте что, все кроме переопреления базовых методов от `Object` считается
логикой. Использование атрибутов `DataAnnotaions` в модели, это нарушение этого правила.

# Как создать Fluent API ?

Для создания `Fluent API` нам нужно переопределить метод `OnModelCreating` в нашем классе 
наследующем `DbContext`. В этом методе мы можем использовать методы `Entity<T>()` и
`Property<T>()` для настройки наших сущностей. Я же в свою очередь считаю что это не самый хороший подход.

Предположим что у нас в программе 10 сущностей. Что же делать тогда ? В таком случае наш метод `OnModelCreating`
будет выглядеть как каша. Поэтому я предлагаю разделить конфигурацию сущностей на отдельные классы.

P.S. Сущность - это класс описывающий таблицу в базе данных.
